## Compte rendu — Phase 4 — 2026-10-21

### 1. Synthèse

La phase 4 livre le paper trading (N2) de la section 8 :
- **F7, pré-trade et conformité.** La Porte de risque (`core/risk_gate/`) est une fonction pure en échec fermé. Elle évalue tous ses contrôles sans court-circuit, sur une photographie figée à la décision.
- **F8, gestion d'ordres.** Une intention d'ordre structurée (Annexe C.2) suit une machine à états journalisée, dans un carnet SQLite en ajout seul. Elle ne s'exécute que sur un simulateur paper maison, recoupé avec le modèle de commission natif de NautilusTrader.
- **F2, réconciliation** après chaque exécution et chaque jour. Un écart bloque les nouvelles intentions jusqu'à ton acquittement.
- **Kill switch d'exécution** (§8.5) : `cerveau kill`, déclencheurs automatiques (pertes, données perdues, incident d'exécution), rapport d'incident, réarmement par toi seul.

La finance reste **en N0** : en pratique, tout est refusé tant que tu ne signes pas sa promotion. La fonction `paper_trading` est aussi bloquée par trois marqueurs : `universe`, `trading_costs` et `exclusions_personnelles` (section 7). Le paper ne tourne aujourd'hui qu'en tests, en évals et sur le marché synthétique de la phase 3.

Les critères de sortie de la section 17 sont remplis :
- **10 000 cas générés** : aucune intention hors limites acceptée, d'après un oracle écrit à part. Distribution : ACCEPTE 3 128 (31,3 %), REDUIT 2 417 (24,2 %), REFUSE 4 455 (44,6 %) ;
- **couverture de `core/risk_gate`** : 100 % des lignes (408) et des branches (70), imposée par `make ci` ;
- **kill switch sous sa cible** de 5 s avec 1 000 ordres ouverts et un adaptateur lent (0,5 s par appel) : le test complet dure 2,12 s, préparation des 1 000 ordres comprise ; l'arrêt seul inclut deux appels d'adaptateur de 0,5 s ; le test exige moins de 5 s ;
- **chaos** : 18 tests sur les quatre familles (coupure réseau, données manquantes, ordre en double, réponse incohérente). Ils ont trouvé deux défauts, corrigés (`04aa673`).

Le dépôt compte 36 nouveaux commits sur `main`, pas encore poussés ; le plan en prévoyait 24. `make ci` passe sur l'arbre final : 3712 tests réussis, 1 ignoré (liens symboliques interdits sur ce poste), en 480,83 s (2726 tests en 171,47 s en phase 3), sans réseau. Les évals hors ligne (357 cas) franchissent toutes leurs portes, avec 0 violation R5. Trois revues ont tourné : sécurité, Porte de risque et quantitative. Leurs constats importants sont corrigés, sauf deux qui attendent ta décision (B188, ACL de B173). Le seul constat bloquant (splits et dividendes du paper, B187) ne bloque qu'avant de renseigner `universe`.

Ces scores mesurent les couches déterministes, avec des modèles scriptés. Ne sont pas mesurés :
- le score du juge sur le golden Finance ;
- un vrai modèle face à la red team `injection_execution` (c'est la red team de domaine qu'exige N1→N2) ;
- toute exécution sur cours réels : pas de source de cours, pas de frais réels.

**Paquets**
- `core/execution/` : intention, UUID v7, machine à états, carnet (`var/paper/orders.db`), interface d'adaptateur, simulateur, marché (photographie, compteurs), réconciliation, rédacteur, boucle quotidienne, rapport.

- `core/policy/` : effet explicite (`executer`, `proposer`, `paper`, `refuser`) ; `live.yaml` à `enabled: true` refuse tout, faute d'adaptateur live.
- `governance/kill_switch` : déclencheurs, annulation bornée par la cible, rapport d'incident dans `var/incidents/`.

**Commandes**

- `uv run cerveau paper run` : traite une fois la journée de décision de maintenant (idempotent). Ordre : kill switch, fraîcheur, exécutions, réconciliation, valorisation et déclencheurs, intentions, politique, Porte, envoi. Il n'a pas d'option `--date` (écart 6).
- `uv run cerveau paper status`, `paper orders`, `paper report` : lecture seule.
- `uv run cerveau paper acquitter` : lève le blocage d'un écart réconcilié ; toi seul, en terminal interactif (D14).
- `uv run cerveau kill` : arrêt total, jamais refusé (R4).
- `uv run cerveau rearm` : toi seul, en terminal interactif, avec une phrase de confirmation ; refusé à Claude Code par les hooks.
- `uv run cerveau status` : kill switch, live, autonomie, compte paper (B54, partiel).
- Un journal hors de `var/` exige `--hors-var` (B103).
