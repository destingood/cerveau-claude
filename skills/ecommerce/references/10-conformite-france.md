# Module 10 — Conformité e-commerce France (gate bloquant)

À appliquer avant de publier une page produit, une promotion, une campagne e-mail, une collaboration créateur ou un
jeu-concours. Si un point critique (★) manque, la publication attend.

Ce module informe ; il ne remplace pas un juriste. Statuts : ✅ vérifié le 18/10/2026 (Légifrance et base LEGI,
administration, CNIL, texte de l'UE) · 🔎 référence à revérifier avant usage. Les règles changent : en cas de doute,
vérifier en direct sur Légifrance, economie.gouv.fr (DGCCRF) ou cnil.fr.

## Sortie du gate

- **Feu vert** : tous les ★ respectés.
- **Feu orange** : seuls des points non ★ manquent → publication possible, correction planifiée (à-faire daté dans le
  cerveau).
- **Feu rouge** : un ★ manque → liste des corrections, publication bloquée.

Le résultat du gate se range dans le cerveau (`brain add -t fact -T "Boutique <Nom> — conformité au <date>" …
--commun non`) pour ne pas tout revérifier à chaque demande.
