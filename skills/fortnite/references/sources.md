## Ce qui n'a pas pu être vérifié

Longueur maximale du titre et de la description ; règle sur les émojis dans un titre ; limites chiffrées de l'API ;
colonnes des exports CSV du portail ; conditions d'âge du compte ou de double authentification ; champs indexés par la
recherche (la description ?) ; règles d'entrée des rangées « New », « Trending », « Popular » ; sens d'une mise à jour
« meaningful » ; actualité du test de « 50,000 impressions » du glossaire ; une règle qui nomme les robots ; unité de la
rétention de l'API (sa description dit « nombre de joueurs », les réponses donnent une fraction : les outils lisent
les deux).
